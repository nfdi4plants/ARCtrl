`ArcWorkflow` describes a computational or analytical workflow. `ArcRun`
describes an execution of one or more workflows. Both can carry metadata,
datamaps, and comments, and runs can reference workflow identifiers.

## Where They Fit

Runs and workflows sit alongside studies and assays in an investigation. Use
them when an ARC needs to describe computational processing, workflow
definitions, run-specific inputs or outputs, or workflow-level datamaps.

For xlsx conversion, use `XlsxController.Workflow` and `XlsxController.Run`.
For JSON, use `JsonController.Workflow` and `JsonController.Run`.
