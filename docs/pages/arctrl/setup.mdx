ARCtrl is distributed for .NET, TypeScript, and Python. The three packages
expose the same ARC model through language-specific package roots.

## Install

Use the package for the language you are working in:

<Tabs syncKey="arctrl-language">
  <TabItem label="F#">

```powershell
dotnet add package ARCtrl
```

For an F# script, reference the NuGet package directly:

```fsharp
#r "nuget: ARCtrl"
open ARCtrl
```

  </TabItem>
  <TabItem label="TypeScript">

```bash
npm install @nfdi4plants/arctrl
```

  </TabItem>
  <TabItem label="Python">

```bash
pip install arctrl
```

  </TabItem>
</Tabs>

## Import From the Public Root

Current examples should import from the package root. In Python, prefer
`from arctrl import ...` over older paths such as `from arctrl.arc import ARC`
or `from arctrl.arctrl import ArcTable`.

## Naming Differences

The public model keeps .NET member names such as `AddColumn`, `RowCount`, and
`ColumnCount` in all languages. Factory helpers use each language's usual style:
TypeScript uses `createFreeText`, while Python uses `create_free_text`.
