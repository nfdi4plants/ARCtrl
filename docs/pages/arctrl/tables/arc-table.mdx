`ArcTable` models ISA annotation tables. It is easiest to use it as a
column-oriented table: each column has a `CompositeHeader` that describes the
column and a list of `CompositeCell` values for the rows.

A logical ARCtrl column can expand to multiple spreadsheet columns. For
example, a term cell may become a value, term source reference, and term
accession number in xlsx. Work with `CompositeHeader` and `CompositeCell`
objects instead of manually composing spreadsheet column names.

## Core Pieces

`ArcTable.init` creates a named table. `AddColumn` appends a typed column and
sets the row count from the supplied cells. `CompositeHeader.Input` and
`CompositeHeader.Output` describe material or data flow. Ontology-backed
headers such as characteristics and parameters use `OntologyAnnotation`.

For cells, use free text for plain identifiers, term cells for ontology terms,
and unitized cells for values with units.
