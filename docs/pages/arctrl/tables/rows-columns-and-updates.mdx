Real ARCtrl applications rarely create a table once and leave it untouched.
Downstream tools commonly add columns, append rows, inspect existing rows, and
update individual cells after parsing user input or external data.

## Indexing

`GetCellAt` and `UpdateCellAt` use zero-based column and row indexes. In the
example, column `1` is the sample output column and row `2` is the third row.

Use `RowCount` and `ColumnCount` to guard UI actions and data imports before
writing into a table. ARCtrl validates row lengths when populated rows are
added.
