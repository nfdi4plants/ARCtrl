Datamaps describe data files and data fragments inside an ARC. A `Datamap`
contains `DataContext` rows that can store a file path, selector, label,
description, object type, unit, and comments.

Use datamaps when a file needs more structure than a table cell can provide,
for example when one CSV file contains multiple measured entities or when a
workflow output should be annotated separately from the assay table.

## Convert Through XLSX

Use `XlsxController` for xlsx conversion. The controller surface is the stable
cross-language API; direct static or extension helpers may exist in F#, but
they are not the portable path for TypeScript and Python.

This example converts a datamap to an in-memory workbook and back. File-based
code uses the same controller family: `toXlsxFile` / `fromXlsxFile` in F# and
Python, and `toXlsxFileAsync` / `fromXlsxFileAsync` in TypeScript.

## Attaching Datamaps

Datamaps can belong to studies, assays, workflows, and runs. Keep paths
relative to the ARC where possible, such as
`assays/Measurement/dataset/results.csv`, so the same metadata works locally
and in remote storage.
