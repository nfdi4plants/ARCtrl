ARCtrl JSON is the native JSON representation of ARCtrl model objects. Use it
when you want to persist or exchange ARCtrl objects without converting to
ISA-JSON or RO-Crate.

## Roundtrip an Investigation

`JsonController` groups JSON helpers by model type. The investigation helper is
the usual entry point for top-level ISA metadata. Prefer these controller
helpers for documentation and application examples because they are exposed in
F#, TypeScript, and Python.

## Choosing a JSON Format

Use ARCtrl JSON for application state and ARCtrl-to-ARCtrl exchange. Use
ISA-JSON when interoperating with ISA tooling. Use RO-Crate JSON-LD when you
need linked-data publication or crate metadata.

The same pattern applies to studies, assays, workflows, runs, datamaps, people,
and ontology annotations: choose the controller helper for the object type,
serialize, and deserialize through the matching helper.
