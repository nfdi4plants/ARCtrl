ARCtrl lets applications create, inspect, serialize, and write ARC metadata.
Most code follows the same pattern: build or load model objects, edit them in
memory, then serialize them or write them back through ARC IO contracts.

The smallest useful mental model is:

- `ArcInvestigation` is the top-level ISA metadata object.
- `ArcStudy`, `ArcAssay`, `ArcWorkflow`, and `ArcRun` sit below an
  investigation.
- `ArcTable` stores study and assay annotation tables.
- `Datamap` describes data files and fragments.
- `JsonController`, `XlsxController`, and the `ARC` contract APIs are the
  portable IO and serialization surface.
