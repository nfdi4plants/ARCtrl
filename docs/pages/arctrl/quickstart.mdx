This quickstart introduces the normal ARCtrl workflow: create or load ARC
metadata, edit the in-memory objects, then serialize or write the result.

The smallest useful ARC usually contains:

- an `ARC` container
- an `ArcInvestigation`
- one or more `ArcStudy` objects
- one or more `ArcAssay` objects
- annotation tables on studies or assays

## Next Steps

After building tables, the next common tasks are:

- attach tables to a study or assay
- serialize the investigation to ARCtrl JSON or ISA-JSON
- write metadata back to an ARC scaffold
- use contracts for custom storage backends such as DataHUB file access
