Updating an ARC is a composition of the smaller workflows from the concept
pages: discover files, load metadata, edit model objects, and write the changed
metadata back through contracts.

## Workflow

1. Start from a file listing or a local ARC folder.
2. Build an ARC shell and read the required metadata contracts.
3. Find or create the study, assay, run, or workflow you need to update.
4. Edit tables, datamaps, or top-level metadata in memory.
5. Request write contracts and fulfill them in your storage backend.
